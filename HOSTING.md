# Hosting

This POC is currently a static dashboard prototype and can be hosted on GitHub Pages immediately.

## Public URL

After GitHub Pages is enabled, the expected URL is:

```text
https://brettswensen.github.io/broker-training-portal-poc/
```

## Current hosting choice

- GitHub auth is available.
- Vercel CLI is installed but not logged in yet.
- GitHub Pages is the fastest no-extra-login option for this first public preview.

## Next version

When transcripts are available, the POC can be upgraded to a Next.js/Vercel app with server-side ingestion and an AI answer API.
