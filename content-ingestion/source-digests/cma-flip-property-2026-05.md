## Key Broker Guidance

### Evaluating Subdivision Potential

**Flag Lot Rules:**
- Most cities allow only ONE home off a flag lot (not two)
- Must have minimum width for the flag road access
- Stub road access from cul-de-sac can change the math entirely
- Always verify with city planning before promising subdivision

**What to Check:**
1. Zoning allows subdivision?
2. Minimum lot size requirements?
3. Road width requirements?
4. Access type (flag road vs stub road)?

### Land Comp Methodology

**For Land (Different from Homes):**
- Go back about 1 year (land moves slower than homes)
- Use 4 statuses: Active, Under Contract, Pending, Closed
- **Exclude:** Commercial, luxury, canyon/boonies outliers
- Focus on same city/neighborhood
- Verify on map view that comps are comparable location
- Look for similar lot sizes (quarter acre, third acre)

**Example from Training:**
- Springville quarter-acre lots in planned communities: ~$130K
- Three lots = $390K retail land value
- Purchase price: $215K
- Gross margin before costs: $175K

### Flip vs Demo Decision

**Quick Math:**
```
Retail value of finished lots: $390K
- Purchase price:               $215K
- Demo cost (if applicable):    ~$10K
- Construction costs:           ???
= Gross profit potential
```

**If land value alone > purchase price:**
- House is essentially free
- Demo becomes viable option
- Interior condition matters less

**If keeping house:**
- Calculate ARV (After Repair Value)
- Estimate rehab costs
- Standard flip formula: ARV × 0.70 - Repairs = Max Offer

## Client-Facing Language

**On subdivision potential:**
> "This lot has potential for subdivision, but we need to verify city approval for access and minimum road width requirements before we can confirm."

**On land valuation:**
> "Land values don't change as quickly as homes, so we're looking at sales from the past year in this specific area, excluding commercial and luxury outliers."

**On flip math:**
> "The math works like this: three finished lots in this area retail for about $130K each. That's $390K in land value. If we can buy for $215K, we have $175K in gross margin before construction costs."

**On demo decision:**
> "The interior is straight flip material. At this price, you could almost knock it down because the land value alone supports the purchase. Let's run the numbers both ways."
